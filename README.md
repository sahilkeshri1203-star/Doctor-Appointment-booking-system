# 🩺 Doctor Appointment Booking System

A simple **Doctor Appointment Booking System** developed using **Python**.  
This project allows users to view available doctors, select a doctor, and book an appointment through a Python-based program.

## 📌 Features

- 👤 Patient details input
- 👨‍⚕️ View available doctors
- 🏥 Select a doctor
- 📅 Choose an appointment date
- 🕐 Choose an appointment time
- 📋 Display appointment details
- ❌ Cancel an appointment
- 🖥️ Simple command-line interface

## 🛠️ Technology Used

- **Python 3**
