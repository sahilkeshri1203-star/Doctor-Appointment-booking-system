# Statement

## Problem Statement
The healthcare sector often faces challenges in managing patient appointments efficiently, especially in small clinics and hospitals where appointment scheduling is still done manually. Patients may struggle to find an available doctor, book appointments at suitable times, and avoid scheduling conflicts. In many cases, doctors and clinic staff need a simple and organized way to manage patient details and appointment records without relying on complex systems.

This project addresses that problem by creating a simple Doctor Appointment Booking System that helps users register patient information, view doctors, select available time slots, book appointments, and cancel bookings when needed. The system aims to reduce scheduling confusion, improve accessibility, and provide a beginner-friendly solution for appointment management.

## Scope of the Project
The project focuses on a basic appointment booking system for a clinic or healthcare center. It includes essential features such as capturing patient details, listing doctors, selecting appointment dates and times, confirming bookings, and managing cancellations. The system is designed as a simple project for learning and demonstration purposes, with a straightforward command-line interface.

The scope includes:
- Patient registration and basic information collection
- Viewing available doctors
- Booking appointments with a selected doctor
- Scheduling an appointment date and time
- Displaying booked appointment details
- Canceling appointments when required
- Maintaining simple records within the application

The project does not aim to provide a full-scale hospital management system with online payment, doctor dashboards, admin authentication, or complex database integration.

## Target Users
The primary users of this project are:
- Patients who need to book doctor appointments easily
- Clinic staff or reception personnel managing appointment schedules
- Students and beginners learning Python application development
- Small healthcare centers that need a simple appointment management solution

## High-Level Features
The Doctor Appointment Booking System includes the following high-level features:
- Patient details entry
- Doctor listing and selection
- Appointment date and time selection
- Booking confirmation
- Appointment record display
- Appointment cancellation
- Simple command-line user interface
- Basic data handling using Python

This project provides a practical and easy-to-understand solution for managing doctor appointments in a lightweight and efficient way.
